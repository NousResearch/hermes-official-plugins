# 记忆百科（Memory Wiki）

[English](README.md)

Hermes 官方插件，用可浏览的主题目录和每日记录查看本地聊天历史，并以只读方式展示固定记忆。原作者、项目历史和贡献名单见[英文说明](README.md#credits)。

## 它能做什么

- **主题**：从会话标题等内容中按确定性规则提取主题，查看关联会话与原文片段。
- **每日记录**：按日期查看会话活动。记录表示聊过什么，不等于任务已被核验完成。
- **最近会话**：快速返回近期对话。
- **固定记忆**：查看 `MEMORY.md` 与 `USER.md` 中的代理笔记和用户资料；内容保持原样。

插件不调用语言模型，不改写聊天，不修改聊天数据库或固定记忆。它不是 Hindsight 记忆库浏览器，也不是语义搜索引擎。

## 中文界面与搜索

桌面端提供中文、英文界面，跟随 Hermes 的界面语言。网页面板提供自动语言选择和插件内语言选择。语言只影响界面文案，不翻译或重写会话标题、聊天原文和个人记忆。

中文主题可以保留中文字符，纯中文与中英混合主题使用稳定且不互相混淆的标识。例如，包含“示例甲检索核对”的主题可以通过“示例甲”或“检索”查询；“示例 API SDK”可以通过“示例”或“API”查询。

**搜索范围是已生成的主题名称和关键词，不是全部聊天正文。** 提取仍是有限的、可解释的规则，不是中文自然语言理解；没有生成主题的内容不会因为加了中文界面就自动变成全文可检索。

## 安装与打开

官方目录发布的版本可以这样安装：

```bash
hermes plugins install hermes-memory-wiki --enable
```

官方目录固定到已审核的提交；源码中的新功能需要维护者合并并更新目录固定版本后，才会通过普通安装或更新命令分发。

### Hermes 桌面端

1. 在运行网关的机器上安装并启用后端插件。
2. 桌面端进入 **能力（Capabilities）→ 插件（Plugins）**。
3. 如未出现，点击 **重新扫描（Rescan）**，然后启用 **Memory Wiki / 记忆百科**。
4. 从侧栏打开页面。

桌面显示开关与后端启用开关独立。远程网关只安装服务端插件并不会自动为客户端安装界面；客户端也需要安装同一插件包的桌面部分。

### 网页面板

```bash
hermes dashboard
```

打开 **Memory Wiki / 记忆百科** 标签。初次安装或更换后端代码后，需要重启提供该页面的服务才能载入新代码。不要在当前网关处理会话的中途直接终止它。

## 数据与隐私

- 通过 Hermes 的会话接口只读访问本地历史，遵循当前连接与配置档案的范围。
- 固定记忆只读展示；修改仍通过 Hermes 自带的记忆工具完成。
- 语言选择不上传聊天记录，也不增加模型调用。
- 反馈问题或贡献代码时，只提交必要代码与虚构测试样例，不提交 `state.db`、个人记忆、配置或密钥。

## 开发与测试

在插件目录运行（Node.js 22.12+；Python 环境需具备 Hermes 核心及测试依赖）：

```bash
npm ci
npm run build
npm run check
npm test
HERMES_AGENT_REPO=/path/to/hermes-agent PYTHONPATH=/path/to/hermes-agent \
  python -m pytest tests/ -o 'addopts=' -q
```

测试使用隔离目录和虚构会话。界面测试不能替代在真实桌面宿主中检查语言切换、路由与主题样式；连接真实历史时不要把真实内容截图上传。

## 卸载

```bash
hermes plugins remove memory-wiki
```
